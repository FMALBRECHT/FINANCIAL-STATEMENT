# Cashflow Life

A free static app you can host on GitHub Pages or paste into Lovable as a design/reference build.

## What it does
- Tracks active income, passive income, expenses, assets, liabilities
- Shows cash flow, net worth, and freedom progress
- Includes real-life deal tracking
- Saves data in browser localStorage
- Exports/imports JSON backup
- Uses Plotly charts via CDN

## Free deployment with GitHub Pages
1. Create a new GitHub repository.
2. Upload these files to the repo root.
3. In GitHub: Settings -> Pages.
4. Under "Build and deployment", choose "Deploy from a branch".
5. Select `main` branch and `/root`.
6. Save. Your app will get a free URL.

## iPhone use
- Open the GitHub Pages link in Safari.
- Tap Share -> Add to Home Screen.
- It will behave almost like an app.

Build a mobile-first personal finance app called "Cashflow Life" with an Apple-style dark UI. The app should track active income, passive income, monthly expenses, assets, liabilities, deal opportunities, net worth, monthly cash flow, and freedom progress defined as passive income divided by expenses. Include cards for metrics, Plotly-style charts for a freedom gauge, income vs expenses bar chart, and asset mix donut chart. Include forms to add/edit/delete records and local persistence.
